# Panconesi local clone

Source: `https://marcopanconesi.com/`

## Local route map

- `/` — editorial home page with split hero, Conversation Piece, Objects and campaign collage.
- `/collections/all` — Shop All product listing.
- `/collections/new`, `/collections/ss26-collection`, `/collections/fw26-collection`, `/collections/signatures`, `/collections/objects`, `/collections/seasonalsale`, `/collections/popular`, `/collections/p-collection`, `/collections/ear-cuffs` — category listings.
- `/collections/ascolto`, `/collections/blow-up`, `/collections/diamanti-constellation`, `/collections/orbit`, `/collections/serpent`, `/collections/stellar-solar` — family listings.
- `/collections/silver`, `/collections/gold`, `/collections/enamel`, `/collections/gems` — composition listings.
- `/collections/ear`, `/collections/finger`, `/collections/neck`, `/collections/wrist`, `/collections/body` — anatomy listings.
- `/products/:slug` — shared product gallery/detail template, including `pierced-serpent-hoops-silver-cao`.
- `/pages/about`, `/pages/campaigns`, `/pages/contact`, `/pages/craft`, `/pages/philosophy`, `/pages/faq`, `/pages/legals`, `/pages/bespoke` — editorial and service pages.
- `/cart` — local cart page; the header cart opens the same state as a drawer.

## Interactions covered

Search, mobile menu, cart drawer, add-to-cart, gallery navigation, product accordions, collection filters, grid density controls, FAQ accordions and newsletter feedback.
